# Верита — финальная версия

В этой версии добавлены 9 тарифов, ручная оплата, реквизиты ВТБ, обязательный номер заказа в комментарии к переводу, кнопка «Я оплатил(а)», несколько администраторов и админское управление ценами. Навигация по тарифам не создаёт лишние сообщения: старые сообщения заменяются новыми.

## Тарифы по умолчанию

Книжная беседа: 750 / 1111 / 1700 ₽
Йога: 750 / 1111 / 1700 ₽
Йога + книжная беседа: 1500 / 1111 / 3000 ₽

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN`.
3. Укажите `ADMIN_IDS` через запятую.
4. `pip install -r requirements.txt`
5. `python bot.py`

Существующую `bot.db` удалять не нужно — новые поля и цены добавляются автоматически.

## Важно

Если в вашем существующем `.env` осталась старая переменная `MANUAL_PAYMENT_TEXT`, удалите её или обновите. Иначе бот продолжит использовать старый текст оплаты вместо текста по умолчанию.

Команда `/buymanual` теперь предназначена только для обращения при ошибке оплаты: `@katerinaa_denisovna`.
